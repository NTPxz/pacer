# pacer

คำนวณเพซซ้อมวิ่งและสร้างตารางซ้อมจากเวลา 10K ที่ดีที่สุด

- **โซนเพซ** E / M / T / I / R จากสูตร VDOT (Jack Daniels & Jimmy Gilbert) พร้อมเวลาต่อ 400 ม. และ กม./ชม.
- **คาดการณ์เวลาแข่ง** 5K, 10K, ฮาล์ฟ, มาราธอน
- **ตารางซ้อม** 8–20 สัปดาห์ สำหรับ 5K–42K วิ่ง 3–6 วัน/สัปดาห์ แบ่งช่วง ฐาน → เพิ่มความหนัก → พีค → ลดโหลด มีสัปดาห์พักฟื้นทุก 4 สัปดาห์ พิมพ์/บันทึก PDF ได้
- รองรับมือถือ/เดสก์ท็อป, โหมดมืด, `prefers-reduced-motion` และจำค่าที่กรอกไว้ในเบราว์เซอร์

## พัฒนา

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ออกที่ dist/
```

Push ขึ้น `main` แล้ว GitHub Actions จะ deploy ไป GitHub Pages ให้อัตโนมัติ
(ตั้งค่าครั้งแรก: Settings → Pages → Source = **GitHub Actions**)

## โครงสร้าง

```
src/lib/vdot.ts    สูตร VDOT, โซนเพซ, คาดการณ์เวลา
src/lib/plan.ts    สร้างตารางซ้อมรายสัปดาห์
src/components/    UI (ลู่วิ่งเคลื่อนไหว, ตารางโซน, ตัววางแผน)
```
