ใช้แบบ guest

ข้อมูลทั้งหมด (เวลาที่ดีที่สุด ตารางซ้อม บันทึกการซ้อม ตู้ถ้วย และรูป) เก็บอยู่ในเบราว์เซอร์ของเครื่องคุณเท่านั้น ไม่มีการส่งไปที่เซิร์ฟเวอร์ใด

เมื่อเข้าสู่ระบบด้วย Google หรือ Facebook

  • เราได้รับเฉพาะ ชื่อ อีเมล และรูปโปรไฟล์ จากผู้ให้บริการ เพื่อระบุบัญชีและแสดงผลในแอป ไม่ขอสิทธิ์โพสต์ ไม่อ่านรายชื่อเพื่อน
  • ข้อมูลการซ้อมและรูปในตู้ถ้วยถูกเก็บบน Supabase เพื่อซิงก์ข้ามอุปกรณ์ เข้าถึงได้เฉพาะเจ้าของบัญชี (บังคับด้วย Row Level Security)
  • เราไม่ขาย ไม่แชร์ และไม่ใช้ข้อมูลของคุณเพื่อโฆษณา ไม่มีระบบติดตามจากบุคคลที่สาม
  • เว็บโฮสต์บน Vercel และ GitHub Pages ซึ่งอาจเก็บ log การเข้าถึงตามปกติของผู้ให้บริการ

การลบข้อมูล

ลบได้ทันทีด้วยตัวเอง: เข้าสู่ระบบ → แตะรูปโปรไฟล์มุมขวาบน → ลบบัญชีและข้อมูล บัญชี ข้อมูลการซ้อม และรูปทั้งหมดบนคลาวด์จะถูกลบถาวร

หากเข้าสู่ระบบไม่ได้ แจ้งขอลบข้อมูลได้ที่ GitHub Issues หรือเพิกถอนการเชื่อมต่อแอปได้ในการตั้งค่า Google / Facebook ของคุณ
